# Phi design

Operate surfaces: a familiar left navigation, central chronological feed, and quiet right context column. Charcoal background, translucent black surfaces, subtle white edges, silver controls. Blur occurs behind the sticky header, navigation and intro to soften actual overlapping surfaces. No pink.

Typography: self-hosted Manrope when available, sans-serif fallback. Main content 15px, generous line height. Display greeting 46–64px, compact titles 20px. Consistent outline SVG icons, 1.6px stroke. Radii 14px on surfaces, pills only for compact controls.

One authored opening moment: a rising silver eclipse, rotating rim, passing horizon, and staggered masked greeting reveals, then a 250ms dissolve to the timeline. No app brand on the opening screen. Reduced motion keeps the static greeting. Native dialogs manage focus. Respect visible focus rings and responsive mobile navigation. Avoid animation on routine navigation. Empty state is honest; no fabricated personal posts or weather.

Timeline header has no subtitle; sidebar has no local badge. The drawn SVG brand mark shares a center line with the wordmark. No persistent composer instructions: embed and math previews appear only when relevant. Timeline widgets use collapsible, compact monochrome surfaces. Functional graph nodes stay still once placed. Contribution intensity uses a five-step grayscale palette; no fabricated activity.

The header sun/moon button switches and persists appearance. GitHub's redundant footer profile link and Obsidian's “Local files only” label are removed. Calendar views live in a configurable, collapsible timeline widget. Google views use a load/unload control; ICS events use compact date and title rows. No fabricated events.
