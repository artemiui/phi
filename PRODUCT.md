# Phi

A local personal timeline built with Node.js, SQLite, HTML, CSS, and JavaScript.

Profiles, posts, images, and settings stay on the local machine. New installations use placeholder profile details and start with optional integrations disabled.

Optional features include local math rendering, click-to-load media embeds, weather, external calendars, GitHub contributions, and an Obsidian graph. Users supply their own integration settings. Widgets can appear in the timeline or right sidebar. The profile preview appears first in the sidebar.
